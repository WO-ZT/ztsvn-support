隐私政策

生效日期及最后更新日期：2026 年 10 月 21 日

本政策适用于由 ZT（下称“我们”）提供的 macOS 应用 ZT SVN，以及本产品与技术支持网站。它说明当前版本如何处理信息，以及你可以如何管理这些信息。

概要

ZT SVN 是连接你指定仓库的 SVN 客户端。应用不设开发者运营的账号或数据存储后台，也未接入广告、用户行为统计或第三方崩溃上报 SDK。本地项目、设置和备份保存在你的设备上；执行远程仓库操作时，相关请求与数据会发送至你指定的 SVN 服务器。

1. 本机处理与保存的信息

为提供版本管理功能，应用会在你授权的范围内读取和处理工作副本中的文件、路径、SVN 元数据、差异和提交历史。应用还会在本机保存项目列表、文件夹访问授权书签、上次打开的项目及外观等偏好设置，以便后续使用。

这些信息用于显示和操作你选择的项目，不会由应用自动上传至我们运营的服务器。应用采用 macOS App Sandbox；首次访问工作副本或其他保存位置时，通过系统文件夹选择器获取授权，并使用安全书签恢复后续访问。

2. 你指定的 SVN 仓库与网络通信

检出、检查远程状态、读取历史、更新、提交、分支操作和导出等功能，需要与相应的 SVN 仓库通信。根据操作，服务器可能收到你的 IP 地址、仓库请求、用于认证的账号信息，以及你主动提交的文件内容、属性、提交说明和分支信息。

接收这些信息的是你自行填写或工作副本已配置的仓库服务器。其运营方可能是你、你的组织或你选择的服务商，并由其管理服务端的日志、访问权限和数据保留。我们不会因提供该客户端而自动获得这些仓库数据；仓库服务商的处理方式应以其政策和你与其的约定为准。

建议使用 HTTPS 连接，并只连接你信任且有权访问的仓库。使用 HTTP 时，通信内容可能未受到传输加密保护。处理服务器证书问题时，请先核对服务器和证书信息再决定是否继续。

3. 登录信息与钥匙串

连接需要认证的仓库时，应用会请求相应的用户名和密码。未选择记住登录信息时，新输入的凭据仅在本次应用会话中按需使用；选择“记住登录信息”并验证成功后，应用会将凭据保存在本机 macOS 钥匙串中，以供后续连接使用。

应用将密码通过标准输入传递给内置 SVN，不将密码放入命令行参数或偏好设置，也不将这些登录信息发送给开发者。可以在“设置 → 登录与安全 → 清除登录信息…”中清除 ZT SVN 的会话凭据及其保存的钥匙串登录信息。此操作不会注销或删除仓库服务端账号。

4. 本地备份、导出与保留

部分可能覆盖或还原本地内容的操作，会先在本机创建备份，其中可能包含源代码、文件内容、路径、属性和状态信息。应用不会自动将备份上传给开发者，也不会自动清理这些备份。可以在“备份管理”中查看并将不再需要的备份移到废纸篓；清空废纸篓后可能无法恢复。

检出与导出的文件保存在你选择的位置，由你管理。应用设置和授权书签通常保留至相应应用数据被清理；记住的登录信息保留至你主动清除。移除工作副本列表项不删除磁盘上的项目，卸载应用也不应视为已自动删除所有工作副本、导出文件、备份或钥匙串条目。

5. 主动联系技术支持

当你主动向 3193152800@qq.com 发送支持邮件时，我们会收到邮件地址、邮件内容及你选择附上的截图或其他材料，用于回复问题和提供支持。邮件服务提供商会为收发与存储邮件处理相关信息。

我们按处理问题和后续沟通的需要保留支持材料，并在不再需要时清理；如因适用法律要求需要保留，则按相应要求处理。你可以通过该邮箱提出查询、更正或删除支持材料的请求，我们会在核实请求并考虑适用义务后处理。

请在发送前对仓库地址、用户名、路径和代码做必要脱敏，不要发送密码、访问令牌、SSH 私钥或未获授权的项目内容。应用不会自动发送支持邮件或上传诊断附件。

6. 网站、第三方服务与系统服务

本网站由 GitHub Pages 托管，网页未嵌入我们设置的广告、分析脚本或追踪 Cookie。浏览网页时，GitHub 及相关网络服务提供方可能为提供和保护网站服务处理 IP 地址等请求信息。详情请参阅 GitHub 隐私声明。

通过 App Store 下载、付款或使用 Apple 的诊断功能时，Apple 会依其自身政策处理相关信息。应用未集成第三方广告、行为分析或自动崩溃上传 SDK，也不利用你的数据进行广告追踪或出售你的个人信息。

7. 你的选择与管理方式

  • 自行决定连接哪个仓库，以及何时执行提交、导出和其他操作。
  • 通过系统文件夹选择器控制工作副本及保存位置的访问授权；适用时，也可在 macOS 系统设置中管理文件访问权限。
  • 在应用中移除项目列表项、清除保存的仓库登录信息，或通过备份管理清理本机备份；使用 Finder 管理检出及导出文件。
  • 如需删除仓库服务器中的账号、代码或提交记录，请联系该服务器的管理员；清理本机数据不会自动删除服务器数据。
  • 就我们收到的支持邮件材料提出隐私请求，请联系下方邮箱。

8. 政策更新

如应用功能或信息处理方式发生变化，我们会更新本页面及顶部日期；涉及重要变化时，会通过应用更新说明、网站或其他适当方式提示。App Store 中的隐私说明也会按实际情况更新。
